🔍 Inspector Struct: C++

Scheda 1: Tipo di Dato (struct) vs Variabile

Una struct definisce solo la struttura (il modello), ma NON crea dati in memoria.

struct Persona { string nome; int eta; }; // Definizione del TIPO Persona p1, p2; // Creazione di VARIABILI reali

⚠️ Errore grave comune: Scrivere Persona.nome = "Mario";.
Il tipo Persona non ha memoria! Devi usare la variabile specifica: p1.nome = "Mario";. Ogni variabile (es. p1 e p2) ha i propri campi indipendenti. Si possono anche copiare intere strutture dello stesso tipo: p2 = p1;.

Scheda 2: Accedere ai Campi e Input/Output (cin / cout)

Per operare su un campo di una struttura (in lettura, scrittura o I/O), devi specificare il nome della variabile seguito dal punto . e dal nome del campo.

p1.eta = 18; // Assegnazione diretta cin >> p1.eta; // Lettura da tastiera cout << p1.nome; // Stampa a schermo

⚠️ Ricorda: Non puoi fare cin >> p1; per leggere tutti i campi in un colpo solo! Devi leggere i singoli campi uno alla volta (es. cin >> p1.nome; cin >> p1.eta;).

Scheda 3: Vettori dentro le Struct e Operazioni/Calcoli

Se una struct contiene un campo di tipo vettore, per accedere ai suoi elementi o effettuare calcoli (es. somme, medie, cicli for) si specifica prima la variabile struct, poi il punto, poi il nome del vettore e l'indice [ ].

struct Registro { string studente; float voti[5]; }; Registro r1; r1.voti[0] = 8.5; // Accesso al PRIMO voto // Calcolo della somma dei voti: float somma = 0; for(int i = 0; i < 5; i++) { somma += r1.voti[i]; }

⚠️ Ricorda: In C++ gli indici partono da 0 fino a N-1. Per fare la media dividi la somma per il numero di elementi (es. float media = somma / 5;).

Scheda 4: Struct dentro altre Struct (Annidamento)

Quando un campo di una struct è un'altra struct, si concatenano gli operatori punto . per accedere ai dati più interni (anche con `cin` e `cout`).

struct Data { int gg, mm, aa; }; struct Studente { string cognome; Data dataNascita; // Struct dentro struct }; Studente s1; s1.dataNascita.aa = 2007; // Assegnazione cin >> s1.dataNascita.gg; // Input da tastiera cout << s1.dataNascita.mm; // Output
